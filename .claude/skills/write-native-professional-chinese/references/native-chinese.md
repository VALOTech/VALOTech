# 中文母语指南 —— 去翻译腔、去 AI 腔，写得自然

本文件的作用：把「像母语者一样写中文」从*靠临场发挥*变成*可复现*。多数不自然的中文并非语法错，而是带**翻译腔**（照搬英文结构）或**AI 腔／官腔**（空泛、对仗、堆砌）。下面逐一点名并给出改法。写或审一段中文前，先对照本清单，再判定是否合格。

`lint_style_patterns.py` 只能抓到其中一部分。**「lint 干净」不等于自然。** 下面这份清单才是真正的检验；linter 只是粗滤网。

## 1. 翻译腔／AI 腔 —— 点名与改法

每行：待避免的写法 → 为什么读起来生硬 → 改法。并非绝对禁止；若该写法在语境中确实准确自然，可保留。但默认改。

| 病症 | 为何生硬 | 改法 |
|---|---|---|
| 「的」字连串（一个非常重要的功能的设计） | 定语层层套「的」，照搬英文长修饰。 | 拆句、少用「的」：改成短句或换语序。 |
| 滥用「被」（问题被解决了／数据被加密） | 中文被动远少于英文，多为主动。 | 改主动：「我们已解决」「我们会加密你的数据」。 |
| 轻动词填充：「进行优化」「作出决定」「给予支持」 | 「进行／作出／给予」是空壳动词。 | 直接用实义动词：「优化」「决定」「支持」。 |
| 「一个」到处冠（这是一个很好的方案） | 照搬英文冠词 a/an。 | 删：「这方案很好」「这是不错的做法」。 |
| 「值得注意的是」「需要指出的是」开头 | 英文 "It's worth noting" 直译，凑字。 | 删，直接说要点。 |
| 「在当今……的时代／背景下」开场 | 万能空话开场白。 | 删，直接进入正题。 |
| 「众所周知」「毋庸置疑」 | 填充语，常掩盖没根据。 | 删；有依据就给依据。 |
| 官／商套话：赋能、助力、打造、一站式、闭环、抓手、落地、深度、全方位、无缝对接 | 空泛热词，说了等于没说。 | 说具体动作与对象：「统一管理权限」「减少误报」。 |
| 政务／宣传语域：贯彻落实、切实保障、广大用户、以……为核心、大力推进 | 行政宣传腔，不该进产品文案。 | 换成对「你」说的自然话：「把你放在第一位」「保护你的权益」。 |
| 排比堆砌（安全、健康、和谐、高效、可靠…） | 口号腔，空洞。 | 留一两个有实义的，砍掉凑数的。 |
| 「使得」「从而」滥用 | 翻译腔连接词。 | 用真实关系或合句。 |
| 「性／化」滥挂（可扩展性、便捷化、赋能化） | 抽象后缀堆叠。 | 还原成短语：「更好扩展」「更方便」。 |
| 「我们致力于」「我们始终坚持」 | 企业宣言腔。 | 说做了什么：「我们会持续加强防护」。 |
| 长前置定语（一个能够帮助用户更好地管理时间的工具） | 照搬英文关系从句。 | 拆开：「这工具帮你管好时间」。 |
| 「将会」赘余、「对……进行……的操作」 | 冗长。 | 「会」；「处理……」。 |

`赋能／全方位／无缝对接／贯彻／切实保障／广大用户` 这些是真实反面例：一段带这些词的官腔中文，读者一眼就知道不是给人看的。

## 2. 「的／地／得」与量词 —— 母语者的分水岭

- **的**：定语，接名词（安全的环境）。**地**：状语，动词前（主动地审核）。**得**：补语，动词后（做得很好）。用混是明显的非母语痕迹。
- **量词**别一律用「个」：一项功能、一款产品、一次通话、一条消息、一位用户。但也别过度雕琢；准确即可。

## 3. 语域与「您／你」

中文没有中性第二人称，**不要默认**。先定关系与文体，再选，并全篇一致。

| 场景 | 读者 | 称谓 | 说明 |
|---|---|---|---|
| 年轻向消费产品（交友、社交、游戏） | 个人用户 | **你** | 亲切、平等。 |
| 中性专业产品／工具 | 专业用户 | **你** 或省略主语 | 简洁。 |
| 金融、正式服务、客服、面向长辈 | 客户 | **您** | 尊重、正式；别塞进年轻向 App。 |
| 技术文档、代码注释 | 开发者 | **省略主语**，用祈使句 | 「运行……」「检查……」。 |

一旦选定「你」或「您」，不要中途混用。

## 4. 地区变体 —— 陆／台／港不可混用

同一文本内不得混用简繁、术语、标点与排版规范。先确定目标市场（`zh-CN` / `zh-TW` / `zh-HK`），沿用现有文本的字形与规范。

常见术语对照（陆 / 台）：软件·軟體、网络·網路、视频·影片、用户·使用者、信息·資訊、质量·品質、服务器·伺服器、打印·列印、屏幕·螢幕、智能·智慧、登录·登入、默认·預設、卸载·移除、点击·點選。

- **不要「简转繁」交差。** 把「智能审核／用户」直接转成繁体字，仍是大陆用语，台湾读者一眼看穿。要换台湾语汇（智慧、使用者）并去掉大陆政务腔。
- 港澳用语又与台湾不同，按目标市场处理。

## 5. 排版细节（UI／HTML／按钮最易错）

- **标点用全角**：，。！？：；「」『』（）—— …… ；纯拉丁字母／代码内部用半角。
- **中西文之间加空格**（house style，推荐）：「使用 Amavo 的 API」比「使用Amavo的API」易读；数字与单位同理。全篇统一。
- 全角标点前后**不再加空格**。
- **引号**：`zh-CN` 用 `""''`；`zh-TW`／`zh-HK` 用 `「」『』`。不要混。
- 省略号「……」（两个字符六点），破折号「——」。
- 数字：计量一般用阿拉伯数字（20%、3 次）；成语、概数、正式场合可用中文数字。大数按「万／亿」为节（十万、一千两百万），不是英文的千分位思维。
- **UI 长度**：中文通常比英文短；但按钮别硬缩到失义。放不下就提出设计问题，不要静默删字。

## 6. 词汇与命名

- 目标市场常用、专业的表达优先。
- 产品名、framework、API、代码标识、通行缩写，在本地译法不常用或有歧义时**保留英文**。
- 产品与开发者场景用简洁、功能明确的命名，**不用妨碍理解的文学化隐喻**（例：一个可配置规则集叫「Constitution」，别直译「宪法」；按功能叫「行为准则」「规则设置」，并服从已批准术语）。
- house term 未定则标注、别自作主张（留一致选择 + 提示需审）。

## 7. 前 → 后示例（段落级）

**官腔／AI 腔原文：**
> Amavo 安全中心全面赋能平台治理，通过无缝整合的智能审核能力，全方位提升会员的安全保障水平。我们致力于打造一个安全、健康、和谐的交友环境，深入贯彻用户至上的核心理念，切实保障每一位用户的合法权益。

诊断：赋能 · 无缝整合 · 全方位提升 · 我们致力于打造 · 排比（安全、健康、和谐）· 深入贯彻……核心理念 · 切实保障……合法权益 · 广大用户腔。

**改写（台湾使用者，对「你」说话，不夸大、不无中生有）：**
> 在 Amavo，我們希望你每次認識新朋友都能放心。安全中心會在背後幫你把關，主動審核平台內容、留意可疑狀況，盡量在問題找上你之前先攔下來。你的安全和權益，一直是我們最在意的事。

注意：改写用「盡量」保留了诚实分寸，没有承诺「全面、可靠」的绝对安全，也没有把来源未提的功能（封锁／检举／验证）硬塞进来。这是*写得好*与*说过头*的界线。
