# English examples

## Generic value claim
Weak: The solution provides a robust and comprehensive approach that enables the organization to enhance security and optimize operations.

Better: The platform centralizes identity policies, access reviews, and privileged-session monitoring. This gives the security team one control point for enforcing access rules and investigating exceptions.

## Cosmetic transition
Weak: The tools generate alerts. Furthermore, incident ownership is unclear.

Better: The tools generate alerts, but unclear ownership delays triage and escalation.

## Unsupported certainty
Weak: The control will eliminate unauthorized access.

Better: The control reduces unauthorized access risk by enforcing role-based approvals and recording privileged sessions. Its effectiveness still depends on policy coverage and operational monitoring.

## Executive finding
Weak: Several issues were identified and should be addressed to improve the overall control environment.

Better: Access reviews are performed, but evidence is incomplete for two privileged systems. Management should assign an owner and complete the missing reviews before relying on the control for year-end assurance.

## UI error
Weak: An error occurred. Please try again.

Better: The file could not be uploaded. Check that it is under the size limit, then try again.

## Legal copyedit boundary
Source: The supplier may disclose the information only where required by law.

Safe edit: The supplier may disclose the information only when disclosure is required by law.

Unsafe edit: The supplier can disclose the information when appropriate.
