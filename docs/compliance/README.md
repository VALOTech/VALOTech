# Compliance sources

The **text** of a regulation, and nothing else: statute sections, guidance notes,
and an attestation the company has actually made. Operational rules — what the
product does about a regulation — live in the PRD's rule catalogue and in the
design that implements them, never here.

The split exists because a rule paraphrased from memory is the most expensive
kind of wrong: it reads as authoritative, it is never checked, and it is wrong
in the direction that feels safe. A claim about the law cites a section and the
file it was read from.

What this repository will need:

| Path | What |
|---|---|
| `sg/pdpa.md` | Personal Data Protection Act 2012 — consent, access and correction, breach notification, the DPO obligation |
| `global/gdpr.md` | The articles that apply when an investor is in the EU |

Both land with `LEGAL-SG-001` and `LEGAL-GLOBAL-001`, which cannot close on a
summary written from recollection.
